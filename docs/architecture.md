# ProjectSetu Architecture

## Overview

ProjectSetu is designed as a digital platform that connects citizens, universities, students, researchers and industry partners for collaborative problem solving of societal challenges.

## Main Components

### 1. Citizen Layer

Citizens can report societal challenges through the platform using text, voice input, location information and supporting evidence.

### 2. Challenge Management

Reported challenges can be organised, explored and analysed so that relevant problems can be identified for further action.

### 3. University Collaboration

Universities and students can discover challenges and contribute ideas, research, projects and solutions.

### 4. Industry and CSR Collaboration

Industry partners and CSR stakeholders can identify relevant challenges and support suitable solutions and initiatives.

### 5. AI-Assisted Workflow

AI-assisted functionality can help with challenge triage and organisation of reported problems.

### 6. Dashboard

Dashboards provide an overview of challenges and related information for monitoring and decision making.

## Prototype Flow

Citizen reports a challenge
→ Challenge is organised and analysed
→ Relevant universities and contributors discover it
→ Ideas and solutions are developed
→ Industry / CSR partners can support suitable solutions
→ Progress can be monitored through dashboards

## Technology

The current project submission includes an interactive web prototype built using HTML, CSS and JavaScript, with concepts for voice input, location-based reporting, evidence upload and AI-assisted workflows.
